## 🧠 Overview

A real-time **Intrusion Detection System (IDS)** for Industrial Control Systems using network traffic analysis and behavior-based threat detection. Integrated with **AWS IoT** and **Azure Security** for cloud-based monitoring and cyber resilience.

- Detects and mitigates **95% of suspicious packets** in industrial IoT networks
- Enhances system security by **40%** using ML-based threat classification
- Deployed on cloud with secure remote monitoring for industrial automation

---

## ⚙️ Features

- Real-time network traffic analysis
- Behavior-based intrusion detection
- ML model for threat classification (Logistic Regression)
- Flask web dashboard with live prediction
- AWS IoT + Azure Security cloud integration
- 5G network intrusion dataset support

## 🚀 How to Run

### 1. Clone the repo
```bash
git clone https://github.com/sanjay10code/Data-Driven-Intrusion-Detection-System-for-Industrial-Control-Systems
cd Data-Driven-Intrusion-Detection-System-for-Industrial-Control-Systems
```

### 2. Install dependencies
```bash
pip install flask scikit-learn pandas numpy joblib
```

### 3. Extract the dataset
Download and extract `5gintrusion.zip` — place `5gintrusion.csv` inside the `Flask App/` folder.

### 4. Run the Flask app
```bash
cd "Flask App"
python app.py
```

### 5. Open in browser
```
http://localhost:5000
```
